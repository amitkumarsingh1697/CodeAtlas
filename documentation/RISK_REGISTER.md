# Risk register

**Scales.** Likelihood (L) and impact (I) run from 1 (low) to 3 (high). Score = L × I, so the highest possible score is 9.

**Review cadence.** Review at the end of every sprint. Close a risk only with evidence.

**Scope.** CodeAtlas and ArchLens only. The CVForge and browser-extension risks (S-01 to S-04, K-02, K-05, K-07, P-01, P-03, C-01) were removed on 2026-11-14 when this repository was extracted from NEXORA; they stay in the NEXORA repository. D-01 (no remote repository) was closed the same day: the code lives at github.com/amitkumarsingh1697/codeatlas. The audit's register, [docs/audit/TECHNICAL_RISK_REGISTER.md](../docs/audit/TECHNICAL_RISK_REGISTER.md), adds the accuracy, packaging, licensing and commercial risks found on 2026-11-14 (T-, S-, D-, L- and C- prefixes there are separate from the IDs below).
