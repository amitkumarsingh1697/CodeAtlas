# CodeAtlas client pitch deck: technical notes

Version 1, 22 November 2026. How the deck is built, what moves and how, where it plays, what was and was not tested, and how to change it.

## 1. What was built, and how

The deck is generated by code, so it can be rebuilt for each prospect in a minute and every number traces to its source.

| Step | Tool | Script |
| --- | --- | --- |
| Product screenshots | CodeAtlas service (local) + Playwright Chromium 1.63.0 | `capture/final*.js` |
| Brain video frames | CodeAtlas offline brain map + Playwright, scripted drag, one frame per animation step | `capture/vid.js` |
| Brain video loop | ffmpeg 6.1.1 (screen blend over the background, forward + reverse, H.264) | `capture/make-brain-video.sh` |
| Backgrounds, glows, 3D layer stack, framed and tilted screens | HTML/CSS rendered by headless Chromium at 2× | `src/make-assets.js` |
| Slides, layouts, notes | pptxgenjs 3.12.0 (+ sharp 0.33.5, react-icons 5.4.0) | `src/build-deck.js`, content of notes in `src/script.js` |
| Transitions, animations, video playback | Python, edits the slide XML | `src/post-process.py` |
| Design guide PDF, PDF closing page | Playwright → PDF | `src/make-docs.js` |
| Presenter script DOCX | python-docx 1.2.0 | `src/make-script-docx.py` |
| Deck PDF | LibreOffice 24.2 export, plus the "About this PDF" page (pypdf) | see §6 |

Design tokens (colours and fonts) live in one file, `src/tokens.js`.

## 2. Structure inside the PPTX

- 16:9 widescreen (13.33 × 7.5 in), 23 slides in six named sections (Act 1 to Act 6).
- Four layouts: `MAIN`, `HERO_COVER`, `HERO_STATEMENT`, `HERO_CLOSE`. Each slide title is a real title placeholder, so the outline, accessibility checker and slide sorter read it.
- Every object has a readable name in the Selection Pane (Home → Arrange → Selection Pane), such as `Card 2`, `Legend 1 head`, `Method panel`. Images have alt text.
- Speaker notes on every slide, the same text as the presenter script.
- Text is live and editable. Diagrams (slide 17 architecture, slide 19 timeline, cards, tables) are native shapes and tables, not pictures. Product screens and the 3D layer stack are images.

## 3. Animation and transition implementation

### Implemented as native PowerPoint features

| Feature | How | Where |
| --- | --- | --- |
| **Morph transition**, 1.0 s, by object | `p159:morph` inside `mc:AlternateContent`, with a **Fade** fallback for apps without Morph | Every slide |
| Morph continuity | Objects with the same `!!` name on consecutive slides are matched: `!!glowV`, `!!glowC` (the light drifts), `!!brand`, `!!brandName` | Every slide |
| **Entrance animations** | Native effects in `p:timing`: Fade (preset 10), Float In / rise (preset 42), Zoom (preset 53), Wipe from left (preset 22). Durations 0.5 to 1.1 s, staggered 120 to 250 ms, starting automatically on slide entry | Every slide (1 to 29 effects per slide) |
| **Cover video** | MP4 embedded with a poster frame, `playFrom(0.0)` on slide start, muted, `repeatCount="indefinite"` (loops) | Slide 1 |

Animations are editable in the Animation Pane (Animations → Animation Pane), where they appear as normal Fade, Float In, Zoom and Wipe effects.

### Video, not native animation

Only the cover's rotating brain is video. It is a real render of CodeAtlas, recorded frame by frame.

### Static renders (no motion)

All other images, including the 3D layer stack and the tilted screens, are static PNG renders. Their "3D" look is perspective drawn into the image.

## 4. Playback requirements and compatibility

| App | Morph | Entrance animations | Cover video | Fonts |
| --- | --- | --- | --- | --- |
| PowerPoint for Microsoft 365 / 2019+ (Windows, Mac) | Yes | Yes | Plays and loops | Install Manrope and Inter |
| PowerPoint 2016 / 2013 | Falls back to Fade | Yes | Plays | Install fonts |
| PowerPoint for the web | Morph is supported in PowerPoint for the web; not tested here | Most entrance effects | May not autoplay; click to play | Web uses its own fonts; Manrope may be substituted |
| Keynote (import) | No (becomes a dissolve or none) | Partly converted | Usually plays | Install fonts |
| Google Slides (import) | No | Most custom animations dropped | Video not imported; poster frame shown | Manrope and Inter are available in Google Fonts |
| LibreOffice Impress 24.2 | Expected to show a plain transition | Expected to play most effects | Embedded; playback depends on system codecs | Install fonts |
| PDF | None | None (final state) | Poster frame | Embedded |

This table is expected behaviour, based on what each app supports. Only LibreOffice was actually run here, and only to open and render the slides (§5).

Practical advice: present from **desktop PowerPoint 2019 or Microsoft 365** with Manrope and Inter installed. For any other setting, send the PDF.

Without the fonts installed, PowerPoint substitutes a default font and some titles will re-wrap. The Manrope TTFs (OFL) are in `source/fonts`; Inter is at `rsms.me/inter` or Google Fonts.

## 5. What was tested, and what was not

| Check | Result |
| --- | --- |
| `validate.py` (OOXML schema, relationships, content types, slide checks) on the final PPTX | Passed, 22 Nov 2026 |
| Opened with python-pptx; 23 slides, 23 slides with notes | Passed |
| Every animation targets an object that exists, every timing id unique | Checked by the post-processing script (it fails the build otherwise) |
| LibreOffice 24.2 opened the final PPTX and rendered every slide to PDF; all 23 slides inspected visually at each iteration, layout fixes made and re-rendered | Done |
| Presenter script DOCX validated (schema) and rendered | Passed |
| **Playback in real PowerPoint** (Morph, animation timing, video autoplay and loop) | **Not tested.** No PowerPoint is available in this environment. The XML follows the structure PowerPoint itself writes for these effects, but treat it as unverified until someone plays it once in PowerPoint |
| PowerPoint for the web, Keynote, Google Slides | Not tested; the table in §4 states expected behaviour, not observed behaviour |

LibreOffice's rendering is close to PowerPoint's but not identical; line breaks can differ slightly.

## 6. Limitations

- File size: PPTX about 30 MB (the video is 5.4 MB; the rest is high-resolution screenshots). PDF about 10 MB. Some email systems cap attachments at 20 to 25 MB, so share the PPTX by link.
- The PDF has no motion and shows the video's first frame. Its last page says so.
- The brain render excludes translation files and the generated OpenAPI client (see the asset inventory).
- Slide 21's test count (784) is a point-in-time fact from 22 Nov 2026. Update or remove it as the code changes.
- Two placeholder groups (team, contact) must be filled before use.

## 7. Editing

**In PowerPoint (one-off changes):** edit text directly. To restyle every title at once, edit the layouts (View → Slide Master). To change what animates, use the Animation Pane. To keep Morph smooth when you add a slide, copy an existing slide so the `!!` objects come with it.

**From code (repeatable, recommended for each new prospect):**

```bash
cd source
npm install                       # pinned versions in package.json
pip install python-docx pypdf     # for the DOCX and PDF steps
# fonts: copy fonts/*.ttf to ~/.fonts (Linux) or install them (Mac/Windows)

npm run assets                    # renders backgrounds, glows, 3D layers and framed screens into build/img (needed once on a fresh copy)
npm run deck                      # build-deck.js, then post-process.py -> build/CodeAtlas_Client_Pitch_Deck.pptx
npm run docs                      # design guide PDF and presenter script DOCX
soffice --headless --convert-to pdf --outdir build/r build/CodeAtlas_Client_Pitch_Deck.pptx
python3 -c "from pypdf import PdfReader,PdfWriter;w=PdfWriter();[w.add_page(p) for f in ['build/r/CodeAtlas_Client_Pitch_Deck.pdf','build/pdf-note.pdf'] for p in PdfReader(f).pages];w.write('build/CodeAtlas_Client_Pitch_Deck.pdf')"
```

- Client name, date and contact: search `build-deck.js` for `[Client name]`, `[email address]`, `[phone]`, `[Name, role]` and the team card text.
- Speaker notes and presenter script: `src/script.js` (both are generated from it).
- Colours and fonts: `src/tokens.js`.
- New screenshots: run the CodeAtlas service, capture with `capture/final*.js` (pass the session token), crop into `assets/`, then `npm run assets` and `npm run deck`.
- The cover video: `capture/vid.js` (needs a brain HTML from `codeatlas brain`) then `capture/make-brain-video.sh`.

`post-process.py` always starts from the raw pptxgenjs file and stops if an animation names an object that does not exist, so a renamed object is caught at build time.
