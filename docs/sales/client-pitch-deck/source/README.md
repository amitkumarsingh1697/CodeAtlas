# CodeAtlas client pitch deck: source

Rebuilds `CodeAtlas_Client_Pitch_Deck.pptx`, its PDF, the design guide and the presenter script.
Full instructions, compatibility and limits: `../CodeAtlas_Presentation_Technical_Notes.md`.

```
src/tokens.js            colours and fonts (one source for everything)
src/script.js            presenter script = speaker notes + DOCX
src/build-deck.js        slides (pptxgenjs)
src/post-process.py      Morph, entrance animations, cover video playback
src/make-assets.js       backgrounds, glows, 3D layer stack, framed/tilted screens (Chromium)
src/make-docs.js         design guide PDF, "About this PDF" page
src/make-script-docx.py  presenter script DOCX
assets/                  real CodeAtlas screenshots (full size) and their crops
build/img/               brain video, poster and alternate frame (other images are regenerated by `npm run assets`)
capture/                 one-off scripts used to capture screenshots and the brain video
fonts/                   Manrope TTFs (SIL OFL); install Inter separately
qa/brain-mid.jpg         fallback frame used by build-deck.js
```

Quick start (Node 22, Python 3, Playwright with Chromium, LibreOffice for the PDF):

```bash
mkdir -p ~/.fonts && cp fonts/Manrope-*.ttf ~/.fonts/   # make-assets.js loads Manrope from ~/.fonts
npm install && pip install python-docx pypdf
npm run assets && npm run deck && npm run docs
```

Lives in the CodeAtlas repository under `docs/sales/client-pitch-deck/`; the PPTX, PDFs and DOCX next to `source/` are the built outputs.
