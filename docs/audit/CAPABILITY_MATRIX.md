# CodeAtlas capability matrix

**Audit date:** 2026-11-14 · **Commit audited:** `2fc3767` on `claude/project-thread-trwxlj` (same tree as `main`) · **Author:** Phase 1 audit

Statuses follow the master prompt (Phase 1 §B):

| Status                        | Meaning in this matrix                                                                                                                                            |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Verified**                  | Implemented, its automated tests ran and passed in this audit, and it was checked on at least one real public repository in this audit or in a dated repo record. |
| **Implemented, under-tested** | Code exists and tests pass, but tests use fixtures or fakes only, or the real-repository evidence is thin or absent.                                              |
| **Partial**                   | Some of the required behaviour exists; named parts are missing.                                                                                                   |
| **Not implemented**           | No code for it.                                                                                                                                                   |
| **Unsupported by design**     | Deliberately excluded by a spec decision or ADR.                                                                                                                  |
| **Unknown**                   | Not established in this audit; needs investigation.                                                                                                               |

"Evidence" points at code and tests in the repo. "Audit run" means something I executed on 2026-11-14 (see [ACCURACY_BASELINE.md](ACCURACY_BASELINE.md)).
