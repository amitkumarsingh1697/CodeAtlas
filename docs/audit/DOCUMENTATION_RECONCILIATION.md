## 3. Missing or incomplete items in the package

1. **No numbered non-functional acceptance criteria.** NFRs (PRD §6) have no IDs or measurable thresholds; performance says "publish conditions" but sets no ceiling. Suggest NFR-001… with a measurement per item.
2. **The assessment report has no content specification beyond a list** (TDD §12). Needs: section order, which findings are mandatory, how coverage is shown, redaction defaults, a sample. This blocks Sprint 1 design.
3. **No definition of a "supported framework"** per stack (for example "NestJS ≥ 9 controllers with decorators" or "Spring Boot 2.7–3.x MVC"). Needed for the capability sheet and the SOW scope field.
4. **No decision on the open-core boundary**, only that one is needed (01, 17). Engineering cannot design module boundaries (04) without it.
5. **No ground-truth ownership.** Doc 07 asks for "independent manual review" but no reviewer is named. The founder or the second developer must adjudicate.
6. **No target hardware** for the customer-operated run (RAM, OS), although large repos need about 8 GB.
7. **Telemetry policy** says "off or opt-in" (PRD §11) without saying whether CodeAtlas needs any telemetry at all. Current code has none outbound; recommend recording "none" as the decision.
8. **Dates.** The 90-day plan (Blueprint) has "Days 16–30: discovery" in parallel with Sprint 1, but no calendar start date.
